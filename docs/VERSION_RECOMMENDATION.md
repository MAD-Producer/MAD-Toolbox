# Download Recommendation

Download the single application installer for your platform: Windows x64 or
macOS Apple Silicon. Command-line tools are installed separately; the installer
contains neither a preselected tool pack nor an offline WebView2 runtime.

Use [the dependency guide](DEPENDENCIES.md) for current system installation commands
and the status of independent mirror downloads.

# 下载说明

选择与你的平台对应的统一安装包：Windows x64 或 macOS Apple Silicon。
工具依赖单独安装；安装包不包含预装工具包或离线 WebView2 安装程序。

系统安装命令与独立镜像下载的接入状态见[依赖说明](DEPENDENCIES.md)。
