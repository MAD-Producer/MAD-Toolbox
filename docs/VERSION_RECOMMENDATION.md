# Version Recommendation

If you have a stable network connection (i.e., you can access GitHub reliably), we recommend the `Lite` version. It has a smaller package size and installs some useful dependencies on your device, which may also come in handy for your future work.

If you are not familiar with computers, or simply want an out-of-the-box experience, we recommend the `Full` version. It bundles all the essential dependencies, so you can get to work right away. However, its package size is tens of times larger than the `Lite` version, and updating the software may take longer.

---

# 版本推荐

如果你能保证网络连接稳定（即可以稳定访问 GitHub），我们推荐下载 `Lite` 版本。它的安装包体积更小，并且会在你的设备上安装一些实用的依赖，这些依赖在你今后的工作中也可能派上用场。

如果你对电脑不太熟悉，或者只想要开箱即用的体验，我们推荐下载 `Full` 版本。它内置了所有必要的依赖，让你能更快开始工作。但它的安装包体积比 `Lite` 版本大数十倍，且更新软件时可能需要等待更长时间。
